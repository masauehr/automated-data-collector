【非公開の内部実行】Bluesky には投稿しません（B版の比較用）。今日の気象情報の投稿本文を作り、非公開で保存してください。

【手順0】まず天気図VLM解説の判定スクリプトを exec で実行する（出力は JSON）:
   python3 ~/.openclaw/workspace/bin/vlm_status.py
   - status が "ok" → 「VLMあり」モード。today / tomorrow / troughs / pattern を【気圧配置・気圧の谷・雨域の根拠】として使う。
   - status が "fail" → 「VLMなし」モード。VLM には一切触れず、手順1の気象庁MCPの結果だけで書く（reason は最終回答に一言添える）。
   - VLM の cautions に挙がっている話題（前線・台風・気圧の谷など）は、VLM を根拠にせず、必ず手順1のツール結果で裏取りしてから書く。VLM の文中の誤記（「台28号」等）はそのまま写さない。

【手順1】気象庁 MCP サーバー（名前 jma。2026-10-11 に OpenClaw へ登録済み）の次のツールを必ず【すべて】呼んで確認する。ツール名は get_typhoon のように見えるはず（jma__get_typhoon 等の接頭辞が付く場合もある）。MCP ツールが本当に見つからない場合は、存在しないスクリプトを探し回らず、手順4で『MCP ツールが見つからなかった』と報告して終了する（VLMありでも省略しない）:
   - get_typhoon（台風の実況・進路予報。台風が存在する場合は必ず本文に入れる）
   - get_warning / get_early_warning（警報・注意報・警報級の可能性）
   - get_earthquake_info（地震。津波は下の【津波の扱い】に従い、get_tsunami_info は使わない）
   - get_forecast / get_forecaster_comment（全国の天気の概況・気圧配置）
   - get_daily_ranking（最高気温・降水量などの顕著な観測値）

【手順2】日本語で【3行構成・全体250字以内】にまとめる（改行は実際の改行、行間は空けない）:
   1行目: 「🤖AIによる自動生成」で始め、日付と全国の天気概況（気圧配置）。VLMありなら VLM の気圧配置・気圧の谷による雨域（例: 奄美付近の気圧の谷）を反映する
   2行目: 地域ごとの特徴と今日→明日の変化。雨や曇りの原因（高気圧・気圧の谷・低気圧など）が分かる場合は原因も短く書く
   3行目: 注意点。【優先順位】台風 > 特別警報・警報 > 大雨・高波・強風 > 地震（震度4以上や津波関連のみ） の順で、重要なものから入れる。該当がなければ「特に警戒すべき情報なし」
   - 気象庁MCPで確認できた事実と、VLMありモードでの VLM の記述だけを書く。取得に失敗したツールの分野は「なし」と書かず、その分野には触れない（「台風情報なし」と書けるのは、get_typhoon で台風が存在しないと確認できた場合のみ）。
   - 絵文字は1行目の🤖のほか最大1個。ハッシュタグ・URLは本文に入れない（URLはスクリプトがリンクカードとして付ける）。推測や数値の創作はしない。

【台風の扱い（厳守）】台風は get_typhoon の結果に載っているものだけを書く。Web検索や過去の記事・記憶から台風を追加しない。get_typhoon に載っていない台風（すでに温帯低気圧化・消滅したものを含む）は書かない。番号・名称・勢力・位置は get_typhoon の実況値をそのまま使う。
台風の表記は「台風29号（コグマ）」「台風28号（ノロ）」の形式（番号＋「号」、名称は括弧内）。get_typhoon の内部ID（例: 2629, TC2629）や英字コードは本文に出さない。複数ある場合は番号の大きい順ではなく、日本に近い・影響が大きいものを先に書く。
台風の影響は get_typhoon の位置・進路予報から言える範囲に限る。「接近中」だけで済ませず、どの地域にいつ接近するか（または離れていくか）を書く。警報・注意報で確認できない地域への影響は書かない。観測値を入れる場合は地点名を正確に（「鹿児島」ではなく「屋久島」など）。

【手順3】exec で次を実行して保存する（投稿はされない。本文は必ずシングルクォートで囲み、本文中のシングルクォートは使わない）:
   python3 ~/.openclaw/workspace/bin/bsky_post.py --shadow A --text '<本文>'

【手順4】最終回答には、使ったモード（VLMあり／VLMなし＋失敗理由）と、スクリプトの出力（「[shadow:A] 保存のみ…」またはエラー）を返す。失敗しても再実行は1回までとし、二重投稿しない。
【改行の厳守】本文は必ず3つの行（改行2回）に分ける。1行目・2行目・3行目の間は実際の改行で区切り、1つの段落にしない。1行は概ね80字以内にし、VLMの文をそのまま写さず要約する。地名は正確に（平島はトカラ列島であり奄美ではない）。
【VLMと台風】vlm_status.py の出力は、台風に触れる文を除外済み。台風の位置・進路・接近・温帯低気圧化などは get_typhoon の結果だけから書く。VLM由来の「台風が本州南岸に接近」のような見通しは使わない（get_typhoon の予報位置・予報円から言える範囲に限る）。
